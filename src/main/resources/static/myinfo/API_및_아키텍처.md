# API 및 아키텍처

> REST API는 Java에 종속된 기술이 아니라 웹 API를 설계하는 아키텍처 스타일이므로 별도 분류했다.

| 기술·개념 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| REST API 설계 및 구현 | 리소스 중심 엔드포인트, HTTP 메서드, 요청·응답 구조를 이용해 검색, 테스트, 등록 및 조회 기능을 구현했다. | 8 |
| 외부 API 연동 | Upbit, Telegram, Google, Kakao, 날씨 등 외부 서비스의 API를 호출하고 응답 데이터를 가공했다. | 8 |
| Scheduler | 정해진 실행 시각에 반복 작업과 조건 작업을 생성하는 스케줄링 구조를 설계했다. | 7 |
| Queue 기반 작업 처리 | Job Queue와 Collector Queue를 이용해 실행 작업, 재시도, 상태 및 중복 방지 구조를 설계했다. | 7 |
| 캐시 설계 | 데이터 수집 주기, TTL, 만료 시각 및 중복 수집 방지를 고려한 캐시 구조를 설계했다. | 6 |
| 계층형 아키텍처 | Controller, Service, Repository를 분리해 책임을 구분하는 구조로 개발했다. | 7 |
| 비동기 처리 | API 호출과 반복 작업에서 비동기 실행 흐름을 다뤘다. | 6 |
