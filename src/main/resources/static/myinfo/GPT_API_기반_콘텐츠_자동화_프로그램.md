# GPT API 기반 콘텐츠 자동화 프로그램

### 프로젝트 개요

미리 정의한 템플릿과 입력 정보를 기반으로 GPT API가 게시물 콘텐츠를 생성하고, 생성된 결과물을 인스타그램에 자동 업로드하는 콘텐츠 자동화 프로그램을 개발했다.

### 주요 개발 내용

- 사용자가 콘텐츠 주제와 필요한 값을 입력할 수 있도록 구성했다.
- 반복해서 사용할 수 있는 콘텐츠 템플릿 구조를 설계했다.
- 템플릿의 변수와 사용자 입력을 결합해 GPT API 요청을 생성했다.
- GPT API를 이용해 게시물 제목, 본문, 설명 및 콘텐츠 문구를 생성했다.
- 생성 결과를 템플릿에 적용해 최종 게시용 콘텐츠를 만들었다.
- 텍스트와 이미지 파일을 포함한 게시물 결과물을 저장하고 관리했다.
- 콘텐츠 생성부터 업로드까지 이어지는 자동화 흐름을 구현했다.
- 생성된 콘텐츠를 인스타그램에 자동 업로드하는 기능을 구현했다.
- 반복 작업을 줄이기 위해 템플릿 선택, 콘텐츠 생성 및 업로드 단계를 하나의 도구로 통합했다.
- API 오류, 생성 실패 및 업로드 실패를 고려한 처리 흐름을 구성했다.

### 사용 기술

| 구분 | 기술 |
|---|---|
| 생성형 AI | GPT API |
| AI 활용 | 프롬프트 설계, 콘텐츠 생성, 출력 형식 제어 |
| 자동화 | 템플릿 처리, 콘텐츠 생성, 파일 저장, SNS 업로드 |
| 외부 연동 | Instagram 업로드 연동 |
| 데이터 처리 | 템플릿 변수 치환, 텍스트 및 이미지 파일 처리 |
| 핵심 역량 | 생성형 AI 기반 콘텐츠 자동화, 외부 서비스 업로드 워크플로 |

> 이 프로젝트의 정확한 구현 언어, UI 프레임워크, 이미지 처리 라이브러리 및 인스타그램 연동 방식은 현재 정보에서 확정되지 않아 기술명으로 단정하지 않았다.
