# 데스크톱 및 UI

| 기술 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| .NET 8 | C# 데스크톱 프로그램의 실행 환경으로 사용했다. | 7 |
| WinForms | 자동매매와 스마트팜 관련 데스크톱 UI, 상태 표시 및 사용자 조작 화면을 구현했다. | 7 |
| HTML5 | 서비스 웹 화면과 포트폴리오 페이지를 구성했다. | 6 |
| CSS3 | Grid, 정렬, 너비 조절, 반응형 화면 및 상태별 스타일을 구현했다. | 6 |
| 반응형 웹 | 웹과 모바일 화면 크기 차이를 고려한 UI 구성을 다뤘다. | 5 |
