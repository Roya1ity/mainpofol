# 데이터베이스

| 기술 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| MySQL 8.4 | 서비스 운영 DB로 사용했다. Docker 환경 구성, 테이블 설계, 연결 및 초기화 오류를 처리했다. | 8 |
| 데이터 모델링 | 사용자, 브리핑, 스케줄, 작업 큐, 수집 큐, 캐시 및 메시지 구조를 관계형 테이블로 설계했다. | 8 |
| JPA Entity Modeling | 일대다, 외래키, 자기참조, Cascade 및 연관 엔티티 구조를 구현했다. | 7 |
| 인덱스·제약조건 설계 | 중복 방지용 Unique 키, 실행 대상 조회용 인덱스 및 외래키 제약을 설계했다. | 6 |
| 트랜잭션·무결성 | 참조 중인 댓글과 대댓글 삭제, read-only 연결 오류 등 데이터 무결성 문제를 분석했다. | 6 |
| SQLite | 스마트팜 또는 로컬 프로그램의 센서·시계열 데이터 저장 용도로 사용한 경험이 있다. | 5 |
| PostgreSQL / pgvector | 문서 임베딩 및 벡터 검색 저장소 후보로 검토한 단계다. | 2 |
| Qdrant | RAG용 벡터 데이터베이스 후보로 조사한 단계다. | 2 |
