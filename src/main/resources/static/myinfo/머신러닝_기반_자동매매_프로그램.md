# 머신러닝 기반 자동매매 프로그램

### 프로젝트 개요

Upbit 원화 마켓의 코인 데이터를 이용해 가격 방향을 예측하고, 예측 결과에 따라 매수·매도 판단을 수행하는 C# WinForms 기반 자동매매 프로그램을 개발했다.

### 주요 개발 내용

- Upbit API에서 코인 시세와 시간봉 데이터를 수집했다.
- 15분 봉을 기준으로 60분·240분 봉 데이터를 병합했다.
- 기술 지표와 시계열 데이터를 이용해 수백 개의 학습 피처를 구성했다.
- MLP, LightGBM, CNN1D 모델을 각각 학습하고 결과를 비교했다.
- 클래스 불균형 문제를 완화하기 위해 Focal Loss를 적용했다.
- Early Stopping과 SHAP 분석을 이용해 학습과 피처를 검증했다.
- Python에서 학습한 모델을 ONNX로 변환했다.
- C#의 ONNX Runtime에서 모델을 로드하고 실시간 추론을 수행했다.
- 모델 신호를 조합해 매수 조건을 판정했다.
- 최대 포지션 수, 최소 주문 금액, 익절·손절 및 가격 단위 처리 로직을 구현했다.
- WinForms에서 현재 시세, 예측 결과, 포지션 및 거래 상태를 표시했다.
- 다중 시간봉 누락, CNN 입력 순서, ONNX 변환 및 UI 크로스스레드 문제를 해결했다.
