# 머신러닝 및 데이터 처리

| 기술 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| LightGBM | 코인 방향 예측용 이진 분류 모델을 학습하고 파라미터를 조정했으며 ONNX로 변환했다. | 7 |
| MLP | 다층 신경망 모델을 설계하고 Focal Loss와 Early Stopping을 적용했다. | 6 |
| CNN1D | 시계열 입력을 처리하는 1차원 CNN 모델을 설계하고 학습했다. | 6 |
| PyTorch | MLP 및 CNN 모델 학습에 사용했다. | 6 |
| ONNX | Python에서 학습한 모델을 다른 실행 환경에서 사용할 수 있도록 변환했다. | 7 |
| ONNX Runtime | C# 프로그램에서 변환된 모델을 CPU 기반으로 추론했다. | 7 |
| Feature Engineering | 다중 시간봉, 기술 지표 및 수백 개 피처를 구성하고 입력 순서를 관리했다. | 8 |
| 시계열 데이터 처리 | 15분·60분·240분 시간봉을 병합하고 누락 데이터와 정렬 문제를 처리했다. | 7 |
| Focal Loss | 클래스 불균형 문제를 완화하기 위해 신경망 학습에 적용했다. | 6 |
| Early Stopping | 검증 성능을 기준으로 학습을 중단하는 구조를 적용했다. | 6 |
| SHAP | LightGBM 피처 중요도와 주요 변수를 분석하는 데 사용했다. | 5 |
| Pandas / NumPy | CSV와 피처 데이터 처리에 사용한 경험이 있으나 세부 활용 범위는 제한적으로 확인된다. | 5 |
