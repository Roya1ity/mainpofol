# 백엔드 프레임워크 및 라이브러리

| 기술 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| Spring Boot 3 | REST 기반 백엔드 서비스, 설정, 스케줄러, 외부 API 연동 및 운영 애플리케이션 구현에 사용했다. | 8 |
| Spring Data JPA | Repository, 엔티티 조회·저장, 정렬, 관계형 데이터 처리 및 삭제 로직에 사용했다. | 8 |
| Hibernate | JPA 구현체로 사용했으며 영속성, 연관관계 및 실행 오류를 분석했다. | 6 |
| Spring Security | Google·Kakao OAuth2 로그인과 사용자 인증 구조에 사용했다. | 6 |
| OAuth2 | 외부 인증 제공자를 이용한 소셜 로그인 흐름 구현에 사용했다. | 6 |
| Gradle | Java 프로젝트의 의존성 관리, 빌드 및 운영 배포 파일 생성에 사용했다. | 6 |
