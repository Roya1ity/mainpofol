# 생성형 AI, 문서 처리 및 자동화

| 기술 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| GPT API 연동 | 프로그램에서 입력 데이터와 지시문을 조합해 콘텐츠 또는 판단 결과를 생성하는 기능에 사용했다. | 6 |
| 프롬프트 설계 | 목적, 입력 데이터, 출력 형식 및 제한조건을 명시해 모델 응답을 제어했다. | 6 |
| 콘텐츠 생성 자동화 | 템플릿과 GPT 생성 결과를 결합해 반복 콘텐츠를 자동 생성하는 흐름을 구현했다. | 7 |
| 워크플로 자동화 | 입력, 생성, 파일 처리 및 외부 서비스 업로드 단계를 하나의 프로그램으로 연결했다. | 7 |
| RAG | 문서 분할, 임베딩, 벡터 검색 및 검색 결과 기반 답변 구조를 설계·학습 중이다. | 4 |
| PDF 텍스트 추출 | PDFBox, Tika 및 OCR을 포함한 문서 처리 파이프라인을 조사 중이다. | 3 |
| OCR | 스캔 문서 처리를 위한 OCR 모델과 적용 방식을 비교·검토했다. | 3 |
| 문서 임베딩 | Qwen3-Embedding, BGE 및 OpenAI Embeddings를 조사한 단계다. | 3 |
