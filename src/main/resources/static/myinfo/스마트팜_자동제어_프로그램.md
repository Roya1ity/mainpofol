# 스마트팜 자동제어 프로그램

### 프로젝트 개요

스마트팜의 온도, 습도 등 재배환경 데이터를 수집하고 작물별 적정 환경과 비교해 상태를 판단하며, 자동제어 명령을 생성하는 프로그램을 개발했다.

> 실제 하드웨어 장치를 직접 제어한 프로젝트는 아니다.  
> 센서 데이터 분석, 재배 상태 판단 및 제어 명령 생성·시뮬레이션 영역을 구현했다.

### 주요 개발 내용

- 스마트팜 시스템에서 센서와 재배환경 데이터를 수집했다.
- 온도, 습도 등 시계열 데이터를 저장하고 화면에 표시했다.
- 작물별 적정 생육환경 기준과 현재 환경 데이터를 비교했다.
- 현재 환경이 정상 범위인지, 조정이 필요한 상태인지 판단하는 로직을 구현했다.
- 판단 결과를 바탕으로 환기, 온도 및 습도 조절 등의 제어 명령을 생성했다.
- 실제 하드웨어 제어 대신 프로그램 내부에서 제어 결과와 상태 변화를 처리했다.
- GPT API를 이용해 센서 데이터와 재배 기준을 기반으로 판단 결과를 생성하는 기능을 적용했다.
- 데스크톱 UI에서 센서 상태, 판단 결과 및 제어 명령을 확인할 수 있도록 구성했다.
- 로컬 데이터베이스를 이용해 센서 데이터를 저장하고 조회했다.
- 로그인 세션과 HTTP 통신을 이용한 데이터 수집을 다뤘다.

### 사용 기술

| 구분 | 기술 |
|---|---|
| 언어 | C# |
| 데스크톱 | WinForms, .NET |
| 데이터 저장 | SQLite 또는 로컬 관계형 데이터 저장 |
| 데이터 처리 | 센서 데이터, 시계열 데이터, 환경 기준 비교 |
| AI 연동 | GPT API, 프롬프트 설계 |
| 통신 | HTTP 통신, 세션 처리 |
| 핵심 역량 | 스마트팜 환경 판단, 자동제어 명령 생성, 모니터링 UI |
| 제외 범위 | 실제 센서·모터·환풍기 등 하드웨어 직접 제어 |
