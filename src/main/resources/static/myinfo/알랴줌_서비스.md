# 알랴줌 서비스

### 프로젝트 개요

사용자가 원하는 브리핑을 등록하면 설정한 시간이나 조건에 따라 날씨, 코인, 환율, 뉴스 등의 데이터를 수집하고 Telegram으로 전달하는 개인 맞춤형 브리핑 서비스를 개발했다.

### 주요 개발 내용

- Java 21과 Spring Boot 3 기반으로 백엔드를 구현했다.
- 브리핑 정의, 입력·출력 스키마, 사용자 설정 및 조건을 DB 구조로 설계했다.
- 반복 브리핑과 조건 브리핑을 처리하는 스케줄러를 설계했다.
- 작업 실행을 위한 Job Queue와 외부 데이터 수집용 Collector Queue를 구성했다.
- 동일한 수집 요청을 중복 실행하지 않도록 input hash와 Unique 키를 사용했다.
- 외부 데이터에 TTL과 만료 시각을 적용하는 캐시 구조를 설계했다.
- 브리핑 검색, 테스트, 추가 및 실행을 위한 REST API를 구현했다.
- Telegram Bot API를 이용해 사용자에게 브리핑 메시지를 전송했다.
- Google과 Kakao OAuth2 로그인을 적용했다.
- Kakao Local API를 이용해 주소를 검색하고 위도·경도 데이터를 처리했다.
- MySQL을 이용해 사용자, 브리핑, 스케줄, 작업 큐, 캐시 및 메시지 데이터를 관리했다.
- Docker Compose로 Spring Boot, MySQL 및 웹 서버를 구성했다.
- AWS EC2 Ubuntu 서버에 서비스를 배포했다.
- Caddy와 Cloudflare를 이용해 도메인, Reverse Proxy 및 HTTPS를 구성했다.
- Logback 디렉터리, MySQL 초기화, DB read-only, 포트 충돌, Cloudflare 525 및 NXDOMAIN 등의 운영 오류를 분석했다.
