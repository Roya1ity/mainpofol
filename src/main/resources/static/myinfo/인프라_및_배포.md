# 인프라 및 배포

| 기술 | 설명 및 사용 내용 | 점수 |
|---|---|---:|
| Docker | Spring Boot, MySQL 및 웹 서버를 컨테이너로 구성하고 실행했다. | 8 |
| Docker Compose | 개발·운영 Compose 파일을 분리하고 환경변수, 볼륨, 네트워크 및 서비스를 관리했다. | 8 |
| AWS EC2 | Ubuntu 서버 구축, 리전 이전, 서비스 배포 및 운영에 사용했다. | 7 |
| Ubuntu Linux | SSH 접속, 파일 권한, 로그, 프로세스 및 Docker 명령어를 이용해 서버를 관리했다. | 7 |
| Caddy | Reverse Proxy와 HTTPS 구성을 위해 사용했다. | 6 |
| Cloudflare | 도메인, DNS 및 SSL을 연결하고 525와 NXDOMAIN 오류를 분석했다. | 6 |
| SSH | PEM 키 권한 설정과 EC2 원격 서버 관리에 사용했다. | 7 |
| 환경변수 관리 | 운영용 `.env`와 Docker Compose 설정을 이용해 민감정보를 분리했다. | 6 |
| 로그 분석 | Docker, Spring Boot, Logback 및 MySQL 로그를 이용해 운영 오류를 추적했다. | 7 |
