# 점수 기준

| 점수 | 기준 |
|---:|---|
| 9~10 | 복잡한 기능을 독립적으로 설계·구현하고 운영 문제까지 해결 가능한 수준 |
| 7~8 | 실제 프로젝트의 핵심 기능을 구현하고 주요 오류를 해결한 수준 |
| 5~6 | 프로젝트 적용 경험이 있으며 일반적인 기능을 구현할 수 있는 수준 |
| 3~4 | 기본 사용, 프로토타입 또는 학습 경험이 있는 수준 |
| 1~2 | 개념을 조사하거나 도입 후보로 검토한 수준 |

점수는 절대적인 숙련도 측정값이 아니라 현재까지 확인된 경험을 기준으로 한 상대 평가다.
