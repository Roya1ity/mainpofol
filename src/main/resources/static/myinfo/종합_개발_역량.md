# 종합 개발 역량

| 영역 | 평가 |
|---|---|
| 백엔드 서비스 개발 | Spring Boot와 MySQL을 이용한 서비스 설계·구현 경험 |
| 데이터 모델링 | 복수 도메인과 작업 큐를 포함한 관계형 데이터 구조 설계 경험 |
| 외부 API 연동 | 금융, 메시징, 인증, 위치, 날씨 및 SNS API 연동 경험 |
| 머신러닝 | 모델 학습부터 ONNX 변환과 C# 실시간 추론까지 연결한 경험 |
| 데스크톱 프로그램 | WinForms 기반 모니터링·자동화 프로그램 개발 경험 |
| 자동화 | 데이터 수집, 판단, 콘텐츠 생성 및 업로드 워크플로 자동화 경험 |
| 인프라 | Docker Compose와 AWS EC2를 이용한 운영 환경 구축 경험 |
| 생성형 AI | GPT API를 기존 업무 프로그램과 결합한 기능 개발 경험 |
